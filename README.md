# Form Automation Bot

A Python Telegram Bot for authorized users to automate contact form filling using Playwright.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Install Playwright browser:
   ```bash
   playwright install chromium
   ```

3. Configure environment variables:
   Copy `.env.example` to `.env` and fill in your Bot Token and Admin Telegram ID.

4. Run the bot:
   ```bash
   python main.py
   ```
